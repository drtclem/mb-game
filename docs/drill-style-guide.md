# Step 0 drill conventions

Reconstruction guidance derived from architecture §13; this is not the later show-writing style review with Taylor.

- Twelve brass performers with two neighboring player slots; solo controls player 1.
- Every page lasts eight counts, with a separate page for each hold.
- Original, quarter-step line / arc / block dots, straight equal-step transitions, front facing, including backward marching.
- Keep performer order during transitions. The show checker checks continuous pairwise closest approach, not only endpoint spacing.
- This reconstruction limits moves to four 8-to-5 units per count and spacing to at least 1.5 units. Final level-specific step-size limits and style require later tuning.
